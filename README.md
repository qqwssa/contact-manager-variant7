# Управление контактами

Автор: Дмитриев Александр. Вариант №7.

ЛР1: Windows Forms, C#, .NET Framework 4.8, Visual Studio 2022.

## Открытие и запуск

Откройте `ContactManager.sln` в Visual Studio 2022. Выберите Debug / Any CPU, выполните «Сборка решения» и запустите MainProject. На компьютере должны быть установлены средства разработки классических приложений .NET и пакет разработки .NET Framework 4.8.

Введите имя и телефон и нажмите «Добавить». Для удаления выделите контакт и нажмите «Удалить». Поиск ищет часть имени или номера; пустой запрос возвращает весь список. Данные автоматически сохраняются после добавления и удаления и загружаются при запуске.

`contacts.txt` находится рядом с исполняемым файлом. Формат ЛР1: `имя|телефон`. Папка приложения должна быть доступна для записи. При запуске из Visual Studio это `MainProject/bin/Debug`.

## Этапы ЛР1

Работа выполнена с нуля непосредственно по исходному коду методички. Сначала все три класса находились в одном файле. После отдельных сборок и запусков последовательно выделены Contact, ContactManager, форма и Designer. Отдельным исправлением путь к файлу привязан к папке приложения.

По уточнённому пожеланию автора: `v1.3` — исходный проект, `v1.2` — выделение Contact, `v1.1` — выделение ContactManager, `v1.0` — завершённая ЛР1. Эта убывающая нумерация служит обозначением учебных этапов. Сообщения коммитов написаны на русском. Ветки: main и develop.

В ЛР1 реально проверены сборка, запуск, Designer, добавление, обычное удаление, поиск по имени и номеру, запись файла, загрузка после перезапуска, отказ при пустых полях и предупреждение при удалении без выбора.

Последующие лабораторные продолжают проект локально. Их результаты и ограничения проверки отражаются в STATUS.md и Reports в родительской папке.
